> [!tip] This Pokemon has multiple forms:
> It can Mega Evolve into two different forms:
> 	- Mega Charizard X using the Charazardite X
> 	- Mega Charizard Y using the Charizardite Y
It can Gigantamax into Gigantamax Charizard if it has the Gigantamax Factor.

Charizard is a [[type/fire|Fire-type]] Pokémon introduced in [[generation/genone|Generation I]].

# Evolution

It [[evolution-method/index|evolves]] into [[charmeleon|Charmeleon]] starting at level 16, which evolves into [[charizard|Charizard]] starting at level 32.
